# dbtool — редактор баз данных

Простая Windows-программа для просмотра и правки таблиц, отправки SQL-команд,
конвертации между СУБД и быстрой проверки/восстановления базы одной кнопкой.

## Поддерживаемые СУБД

| СУБД | Драйвер | Комментарий |
| --- | --- | --- |
| SQLite | `Microsoft.Data.Sqlite` | файлы `.db`, `.sqlite`, `.sqlite3` |
| MySQL / MariaDB | `MySqlConnector` | хост, порт, логин, пароль, имя базы |
| PostgreSQL | `Npgsql` | хост, порт, логин, пароль, имя базы |
| Access (.mdb/.accdb) и Excel (.xlsx) | `System.Data.OleDb` | на ПК должен стоять драйвер ACE (Microsoft Access Database Engine), иначе программа подскажет ссылку на установку |

Драйвер ACE: если Access/Excel не открывается, установите Microsoft Access Database Engine Redistributable
(https://www.microsoft.com/en-us/download/details.aspx?id=54920), разрядность — как у программы (x64).

## Возможности

- Дерево таблиц слева, данные выбранной таблицы справа.
- Редактирование ячейки двойным кликом, добавление и удаление строк,
  установка NULL через контекстное меню (NULL и пустая строка различаются).
- WHERE-фильтр при загрузке таблицы, кнопка «Обновить».
- SQL-консоль: произвольные команды, вывод результата и затронутых строк,
  подтверждение опасных команд (DELETE/UPDATE без WHERE, DROP, TRUNCATE, ALTER).
- Конвертация: копирование таблиц (схема, ключи, данные) из одной БД в другую,
  например MySQL → SQLite. Целевые таблицы перезаписываются (DROP + CREATE);
  если таблицу перенести не удалось, она удаляется из цели, а список отказов
  выводится в итоговом окне.
- Экспорт результата в CSV, копирование ячеек/строк (переносы строк в ячейках
  заменяются на «\n», чтобы копия разлилась корректно).
- Журнал всех действий и ошибок внизу окна, автозапись в `dbtool-log.txt`
  рядом с программой и кнопка сохранения журнала в файл.
- Кнопка «Исправить БД»:
  - SQLite: `integrity_check`, `foreign_key_check`, `VACUUM`, REINDEX; при
    повреждении — восстановление читаемых таблиц в новый файл `*-fixed.db`;
  - MySQL: `CHECK TABLE` для всех таблиц, `REPAIR TABLE` для MyISAM, `ANALYZE TABLE`;
  - PostgreSQL: `VACUUM ANALYZE`;
  - Access: попытка `Compact&Repair` через JRO/DAO, при недоступности — подсказка.
- Портативная сборка: exe запускается на любом Windows 10/11 x64 без установки .NET.

## Проверка (smoke)

`dotnet run --project tests/smoke/smoke.csproj` — автоматическая проверка ядра:
подключение, схема, правка/удаление строк, NULL, SQL-консоль, «Исправить БД»,
конвертация. Последний прогон: 23/23 OK.

## Стек

- C# 12, .NET 8 (WinForms), портативный режим (self-contained).
- Провайдеры: Microsoft.Data.Sqlite, MySqlConnector, Npgsql, System.Data.OleDb.

## Установка и запуск

Портативный вариант (рекомендуется, чтобы exe запускался «везде»):

1. Установить .NET SDK 10 (или любой SDK с поддержкой net8.0-windows).
2. Запустить `scripts\publish.cmd`.
3. Взять папку `dist\win-x64` — внутри `dbtool.exe` и библиотеки;
   папка копируется на любой ПК и работает без установки.

Разработка/запуск из исходников: `dotnet run --project src\dbtool\dbtool.csproj`.


## Безопасность

- Пароли соединений не сохраняются и не записываются в журнал.
- Все действия с БД фиксируются в журнале для восстановления контекста ошибок.

## Известные ограничения

- Редактирование и удаление строк в таблицах без первичного ключа выполняется
  подбором по всем колонкам; если строку найти не удалось, страница предложит
  обновить данные, правка не запишется.
- Access/Excel требуют установленный ACE-драйвер; для `.mdb` на 64-битной
  Windows может требоваться Access Database Engine 2016 x64.
- Конвертация больших таблиц идёт порциями по 500 строк с транзакциями.
- Excel-источник открывается только для просмотра (правка и удаление отключены).
